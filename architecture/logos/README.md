# Technology logo sources

The architecture flowchart uses technology logo artwork from the [Simple Icons repository](https://github.com/simple-icons/simple-icons), downloaded on 7 October 2026. The original SVG files are retained here; the presentation SVG embeds their paths and applies brand colors so it needs no external resources.
