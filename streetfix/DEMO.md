# Three-minute StreetFix demo

Before the interview: launch the preview, use **Reset demo**, and have a real street-problem JPEG/PNG/WebP ready. Use one tab. If no photo is available, the form offers an explicitly labeled sample. Live AI is optional; Sample AI draft works without credentials.

| Time | Action and talking point |
| --- | --- |
| 0:00–0:20 | Open the map and select **Pothole near the morning bus stop** (SF-001). “Photograph a street problem, get your neighbors behind it, and follow its repair on one shared map.” Show its photo, selected marker, 63 supports, and Planned status. |
| 0:20–1:00 | Close the detail sheet and choose **Report an issue**. Upload a real photo, place a map pin or enter coordinates, and select **Confirm this location**. Add a landmark and a sentence of resident context. Review the report, choose a category, and select **Help describe this issue**. Explain that arbitrary-upload Sample mode organizes text and explicitly does not analyze the photo. If using the known sample, call the draft a curated example. Edit the title/description and submit. Show the new Awaiting review report and marker. |
| 1:00–1:20 | Close the sheet and switch the **Demo role** to **Resident · Leo**. Open SF-001 and select **Support fixing this**. Count changes from 63 to 64, with a supported state. Click again if demonstrating reversal. These are demo identities, not verified residents. |
| 1:20–1:45 | Switch to **City staff**. Compare **Most supported** and **Urgent**: SF-001 is normal priority with 63/64 supports; SF-002 has only 4 supports but a staff urgency reason concerning the accessible route. Community support and staff urgency are separate decisions. |
| 1:45–2:20 | Open **Needs review** and select the new report. Confirm it, review/correct details, assign the appropriate team, choose Normal priority with a reason, select Planned, add a public note, and save. Then select In progress, add “Crew assigned and work has started,” and save. Repair stages advance sequentially. |
| 2:20–2:40 | Close the sheet, return to **Resident · Maya**, and open the same report. Show In progress, the team, and the public update. The intake and repair record are connected. |
| 2:40–3:00 | Filter to Fixed and open **A clear sidewalk on Alder** (SF-004). Show original photo, retained 36 supports, repair history, and illustrative completion photo (a separate scene, labeled). “For a pilot, I would validate report completeness, preparation time, triage time, and resident understanding of repair status.” |

Alternate live mode: configure the server key before the interview, choose Live AI, give explicit consent, and request the draft. If it fails, finish manually. Never claim a curated sample is a model analysis of an arbitrary uploaded photo.

Optional follow-up demonstration: reload the page to show local persistence, or mark a report as a duplicate and show its canonical link and retained original supporters without combining counts.
